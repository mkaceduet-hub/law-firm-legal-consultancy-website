# Lexora Legal — Law Firm & Legal Consultancy Website

A polished, responsive law firm website concept built with **HTML5, CSS3 and vanilla JavaScript**. The design uses a refined navy-and-gold palette, editorial typography and clear content hierarchy to communicate professionalism and trust.

## Live preview
After enabling GitHub Pages, your site will be available at:

`https://mkaceduet-hub.github.io/law-firm-legal-consultancy-website/`

## Features
- Responsive layout for desktop, tablet and mobile
- Sticky navigation with an accessible mobile menu
- Hero section with clear consultation call to action
- Firm introduction and legal practice-area cards
- Team profiles and insights section
- Consultation enquiry form with client-side validation and demo feedback
- Semantic HTML, descriptive image text and reduced-motion support
- No build tools or external JavaScript frameworks required

## Project files
| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content |

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it in your preferred code editor and browser.

## Publish with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the deployment to finish and refresh the Pages settings to find the live URL.

## Customization
Replace the illustrative firm name, lawyer names, portraits, address, phone number, email address and practice-area content with accurate information before using this template for a real firm. The image assets are loaded from Unsplash and Google Fonts are loaded externally, so an internet connection is needed for those assets.

## Important demo notice
This is a front-end portfolio demonstration, not a functioning legal service. The consultation form performs browser-side validation and displays a local confirmation only; it does **not** send, store or process enquiries. Do not enter confidential, personal or legally sensitive information. No attorney-client relationship is created by viewing or using this demo.
